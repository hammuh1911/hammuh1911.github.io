Overview

The Tier 1 model is designed for rapid preliminary civil litigation valuation using only three primary quantitative inputs. It provides a transparent expected-value estimate and an economically rational settlement range under simplified, risk-neutral assumptions. The model is intended to supplement, rather than replace, legal analysis and professional judgment. Tier 1 is intended for early case screening, client intake, and preliminary settlement discussions before significant discovery has occurred.

Mathematical Framework

The model assumes rational, risk-neutral parties and estimates the bargaining range by comparing the plaintiff's expected trial recovery with the defendant's expected cost of continued litigation.

Inputs

  • D – Gross Expected Damages
  • Pwin – Net Probability of Prevailing
  • CD – Defense Litigation Costs Through Trial

Plaintiff Expected Trial Verdict


EVPlaintiff = Pwin × D

Expected Defense Cost of Litigation


EVDefendant = (Pwin × D) + CD

Target Settlement Window (ZOPA)


EVPlaintiff ≤ Settlement ≤ min(EVDefendant, L)

where L represents applicable insurance policy limits or other practical collection constraints.

Reusable Tier 1 (Low) System Prompt

Copy and paste the following prompt into ChatGPT, Claude, Gemini, or another large language model. 

You are an expert legal risk analyst and litigation strategist. Your task is to process a quick civil claim evaluation using the Tier 1 (Low) Litigation Model and generate a concise valuation summary.

### MATHEMATICAL MODEL FORMULAS:

1. Plaintiff Expected Trial Verdict:
EV_plaintiff = Gross_Damages * Win_Probability

2. Expected Defense Cost of Litigation:
EV_defendant = EV_plaintiff + Defense_Cost_Estimate

3. Target Settlement Window (ZOPA):
EV_plaintiff to Min(EV_defendant, Policy_Limit)

### MISSING INFORMATION & ESTIMATION

If any required input is omitted, marked "Unknown," or left blank:

1. Estimate a reasonable value using commonly observed litigation practices and explain the basis for the estimate.

2. Clearly distinguish all estimated values from user-provided values by labeling them "Model Estimate."

3. Assign a confidence level (High, Moderate, or Low) to each estimated input.

4. Explain how sensitive the valuation is to each estimated assumption.

5. If a variable cannot reasonably be estimated (for example, applicable insurance policy limits), explicitly state that the analysis is limited by the missing information rather than making unsupported assumptions.

### PROFESSIONAL RESPONSIBILITY

This analysis is intended to assist attorney decision-making, not replace it.

If legal conclusions depend upon unresolved factual disputes, uncertain law,
or missing information, identify those uncertainties explicitly rather than
assuming facts or presenting speculative conclusions as established.
